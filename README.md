# गढ़वळि समीक्षा — Garhwali review tool

Native speakers listen to short All India Radio Dehradun Garhwali bulletin clips, correct the machine transcript, and judge
machine translations. Corrections are kept on the reviewer's device and sent with the **📤 भेजें** button (WhatsApp/email
share, or a file download), or uploaded automatically if `config.json` names a save endpoint.

Live page: https://aptsalt.github.io/garhwali-review/

Part of the open Garhwali language model project. Audio clips are 2–15 s research excerpts (Prasar Bharati copyright); not for redistribution.
